# 豆类结构食品试验库

本仓库实现豆类质构试验的盲样谱系与复现实验流程：原料、预处理、分样、过程参数、仪器运行和曲线文件通过不可变事件连接，支持盲码隔离、校准治理、批量采集与报告签署。

## 资料范围

- `contracts/domain.schema.json`：领域事件信封、聚合类型与事件名称。
- `data/sample.json`：一条用于本地联调的中文样例。
- `src/`：事件存储与各领域服务模块。
- `tests/`：验证样例与每条领域规则。

## 模块与规则

- `src/store.js`：追加式事件存储。记录一经接收即深冻结，标识不得重复，不得原地改写；更正使用携带 `supersedes` 的后继记录。
- `src/lineage.js`：原料批次 → 预处理 → 分样 → 合样的谱系。分样与合样保持数量守恒，超量取用被拒绝。
- `src/blinding.js`：盲码由独立的盲态管理员签发，配方映射存于密封库、事件只留摘要；解盲前对分析员隔离，解盲需研究内运行全部终结、剔除申请全部确认、调查全部结案。
- `src/calibration.js`：校准有效期登记与失效；失效只冻结受影响仪器在受影响时间窗内的运行，其余运行不受影响。运行开始时钉住当时有效的校准证书。
- `src/measurements.js`：重复测量必须填写理由并关联原测量；人工剔除需理由且由第二人确认，确认前仍计入。曲线按（设备序号，曲线摘要）幂等接收：同键同内容重传不重复计数，同键不同内容开立调查并隔离。
- `src/acquisition.js`：批量采集按运行计划推进检查点，单个运行失败后可从断点续采，已完成运行不重采。
- `src/reports.js`：报告创建即固定试验集合，解盲后方可签署结论；签署后迟到的补录只标记为迟到、只能以附录挂接，不进入已签署报告。`traceReport` 从报告追到原料批次与仪器校准证据；`exportBlindPackage` 导出不含配方标识、摘要可复现的盲样数据包供复核人使用。

个人、机构及商业敏感信息仅向履行职责所需的调用方开放。

## 本地检查

```bash
node --test
```

## 测试与构建

测试命令：

```bash
npm test
```

编译或构建命令：

```bash
npm run build
```

这些命令可在单个 Linux 应用容器内执行，不需要另行启动外部服务。
