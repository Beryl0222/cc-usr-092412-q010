# 豆类结构食品试验库

本仓库记录该项目已确认的领域对象、事件名称和基础校验方式，并提供盲样谱系与复现实验服务的参考实现，便于不同系统交换一致的数据。

## 资料范围

- `contracts/domain.schema.json`：领域事件信封、聚合类型与事件名称。
- `data/sample.json`：一条用于本地联调的中文样例。
- `src/validator.js`：事件信封的最小校验代码。
- `src/lineage/store.js`：追加式事件存储——事件写入即冻结，逐条携带前序哈希构成防篡改链，`verify()` 可重放校验；同一事件序列重放得到同一条链（幂等），任何历史内容被改动都会改变终端摘要。
- `src/lineage/service.js`：盲样谱系与复现实验服务（见下）。
- `tests/`：验证样例符合基础约定，并覆盖谱系服务的全部关键约束。

## 盲样谱系与复现实验服务

`LineageService` 把原料批次、预处理、分样/合样、过程参数、仪器运行和曲线文件通过不可变事件关系连接起来：

- **谱系与数量守恒**：分样时 `Σ子样 + 损耗 ≤ 母样可用量`，合样时 `Σ投入 = 产出 + 损耗`，不满足即拒绝；`traceLineage` 可从任意节点反向追到原料批次与仪器证据。
- **盲码隔离**：盲码只能由独立角色 `blind_admin` 生成并绑定样品，配方↔盲码映射写入封存事件；解盲条件（完成运行数、无未决剔除单）满足前，分析员视图与事件列表一律脱敏。
- **校准失效冻结**：校准失效只冻结使用该版本且落在受影响时间窗内的运行，其余运行不受影响；冻结运行拒绝写入，可凭新的有效校准重新启用。
- **测量复核**：重复测量必须给出理由；人工剔除需理由并经申请人之外的第二人确认。
- **报告签署**：结论引用确定的运行集合并对曲线摘要、测量集合做快照；签署后集合冻结，补录数据打标记单独列出、绝不悄悄并入；变更只能修订产生新版本。
- **批量采集**：逐条检查点，单个运行失败可修正后从断点续传；同一设备序号 + 曲线摘要的重传不重复计数，同一曲线标识内容不一致的进入调查队列。
- **复核数据包**：`buildReviewerPackage` 从已签署报告汇集完整谱系、参数版本与校准证据，未解盲不含配方标识；`manifest` 为内容摘要，同一状态重复构建结果一致，复核人可独立复算。

记录一经接收，标识、发生时间与版本不得原地改写；更正使用新的后继记录。个人、机构及商业敏感信息仅向履行职责所需的调用方开放。

## 测试与构建

测试命令：

```bash
npm test
```

编译或构建命令：

```bash
npm run build
```

这些命令可在单个 Linux 应用容器内执行，不需要另行启动外部服务。
